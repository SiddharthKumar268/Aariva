Aariva — feature guide

Disability management system · 4 roles · 15 features

🔐
Register & login
All roles
Create an account and log in. Each user is assigned a role — Applicant, Case Worker, Doctor, or Admin — which controls what they can see and do.
All roles
🗂️
Role-based dashboards
All roles
Each role gets its own dashboard view. Applicants see their case status. Case workers see pending submissions. Doctors see cases awaiting evaluation. Admins see everything.
All roles
🔔
Notifications panel
All roles
Every user gets real-time status update alerts on their dashboard whenever their case moves forward — submitted, under review, approved, rejected, or flagged.
All roles
📍
Case status tracking
Applicant
Track your disability case in real time through every stage: Pending → Under Review → Approved / Rejected. See exactly where your case is without calling anyone.
Applicant
📝
Case submission
Case worker
Submit a new disability case on behalf of an applicant. Fill in personal details, disability information, and supporting context through a validated form.
Case worker
📎
Document upload
Case worker
Attach medical documents (PDFs or images) directly to a case. Files are stored securely and linked to the case record for doctors and admins to review.
Case worker
✅
Form validation
Case worker
Both client-side and server-side validation catch errors before submission — missing fields, invalid file types, or incomplete data — with clear error messages.
Case worker
🩺
Medical evaluation
Doctor
Review assigned cases, add a diagnosis, write evaluation notes, and upload a medical evaluation report. Your findings feed directly into the admin decision process.
Doctor
🏛️
Admin review dashboard
Admin
View all cases across the system. Filter by status (Pending, Under Review, Approved, Rejected). See full case history, uploaded documents, and medical evaluations in one place.
Admin
⚖️
Approve / reject cases
Admin
Make a final decision on any case — approve or reject — and write a written justification or remarks. The decision is logged and the applicant is notified instantly.
Admin
❓
Clarification requests
Admin
Flag a case and request additional information before making a decision. The case worker is notified and can resubmit with updated details.
Admin
📋
Audit logs
Admin
Every admin action and case status change is automatically recorded with a timestamp and user ID. Full traceability for compliance and accountability.
Admin
🖨️
Case summary report
Admin
Generate a printable summary of a case's full lifecycle — submission details, medical evaluation, admin decisions, and all status changes in chronological order.
Admin
⚠️
Escalation for delays
Admin
Cases that stay in Pending or Under Review beyond a set time threshold are automatically flagged for escalation, so nothing slips through the cracks.
Admin
🔒
Session management
All roles
Secure login sessions with automatic timeout after inactivity and a manual logout button. Prevents unauthorized access if a browser is left open.
All roles

How to run Aariva

1
Open a terminal and start MongoDB: mongod --dbpath "C:\data\db" — keep this window open, wait for "Waiting for connections"
2
Open a second terminal, go to your project: cd D:\Python\Avi.py\aariva
3
Start the server: npm start — you should see "Aariva running on http://localhost:5000" and "MongoDB connected"
4
Open your browser and go to http://localhost:5000
5
Register an account and pick a role — start with Admin to see all features, or Case Worker to submit a test case
